### 介绍

`DSH Remote Instance` 通过 SSH 把其他设备上的 DeepSeek Harness 接入当前 DSH，让代理将任务分派给远端并行执行，随时查看进度、结果或取消。插件提供设备管理与远端会话入口，可浏览会话、阅读历史、发送消息和停止回合，支持 Linux、macOS 与 Windows 远端。
