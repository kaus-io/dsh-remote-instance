第三个 alpha：支持密码登录，远端覆盖 Linux / macOS / Windows。

### 新增
- **密码认证**：设置面板只填账号、IP、密码；密码存 `$DSH_HOME/remote-instances.secrets.json`（`0600`，与清单分离），只经 `SSH_ASKPASS` 交给 ssh，不进 `argv`、日志、作业输出或工具结果。
- **三平台**：POSIX 走登录 shell；Windows 走 PowerShell（`-EncodedCommand` + UTF-16LE base64，避免任何引号歧义），由 `probe` 自动识别并缓存平台，`ask` 按平台拼命令。
- 名字留空时按 IP 派生（`100.68.98.76` → `100-68-98-76`）。
- 首次连接用 `accept-new` 接受并锁定主机指纹，指纹变化仍然失败。
- 设备列表显示认证方式（密码/密钥）与平台徽章。
- `remove` 同时删除保存的密码。

### 修复
- 压掉 PowerShell 的 CLIXML 进度噪声与 OpenSSH 的 post-quantum 警告（`LogLevel=ERROR`，主机指纹不匹配仍是错误）。

### 安装
```sh
dsh plugin --profile web add @kaus-io/dsh-remote-instance@1.0.0-alpha03
```

### 兼容性
`engines.dsh`: `>=0.2.1-rc.3 <0.3.0`

### 已知限制
- 密码认证要求运行 DSH 的机器是 Linux/macOS（Windows 宿主没有可用的 `SSH_ASKPASS`），那里请用密钥。
- 远端必须已安装 `dsh` 与目标 profile；`headless` 默认不读 GUI 凭据，需要远端有 `DEEPSEEK_API_KEY`。
