第一个 alpha：把另一台设备上的 DSH 通过 SSH 接进来，并把任务派发成本会话的后台作业。

### 包含
- `remote_instance` 工具：`instances`、`add`、`remove`、`probe`、`ask`、`jobs`、`status`、`cancel`。
- `ask` 执行 `ssh <host> dsh --profile headless --json`：prompt 只走 stdin，作为普通后台作业运行，可并行、可取消、可读流式进度与最终回答。
- 设备清单存 `$DSH_HOME/remote-instances.json`（`0600`、临时文件 + rename、字段严格校验、坏行跳过并报告）。
- 设置 → 远程实例：登记/替换、探测、两步确认移除。
- 密钥认证（`BatchMode=yes`，永不提示密码），首见主机指纹仍要预先接受。
- CI（类型检查 / 产物检查 / 测试）与 Release 自动发布 workflow。

### 安装
```sh
dsh plugin --profile web add @kaus-io/dsh-remote-instance@1.0.0-alpha01
```

### 兼容性
`engines.dsh`: `>=0.2.1-rc.5 <0.3.0`

### 已知限制
- 只支持密钥认证。
- 远端必须是 POSIX 系统，且已安装 `dsh` 与目标 profile。
