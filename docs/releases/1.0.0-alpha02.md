第二个 alpha：把最低 DSH 版本从 `0.2.1-rc.5` 降到 `0.2.1-rc.3`。

### 变更
- `engines.dsh` 改为 `>=0.2.1-rc.3 <0.3.0`：运行 rc.3 / rc.4 的部署也能安装。

### 其余
功能与 `1.0.0-alpha01` 相同：SSH 任务派发（`ask` → 后台作业）、设备清单、设置面板、密钥认证、CI 与自动发布。

### 安装
```sh
dsh plugin --profile web add @kaus-io/dsh-remote-instance@1.0.0-alpha02
```

### 已知限制
- 只支持密钥认证。
- 远端必须是 POSIX 系统，且已安装 `dsh` 与目标 profile。
