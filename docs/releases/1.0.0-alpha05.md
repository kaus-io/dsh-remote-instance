会话操作改成插件自带的桥接服务，桌面版也能当远程设备用。

### 新增
- **插件自带 HTTP 服务**：每台装了插件的 DSH 在宿主进程里起一个只绑 `127.0.0.1`、端口自动分配的服务（`/v1/info`、`/v1/sessions`、`/v1/history`、`/v1/create`、`/v1/prompt`、`/v1/cancel`），默认开启，无需改任何配置；端口与 token 写进 `$DSH_HOME/remote-instance-bridge.json`（`0600`）。
- **SSH 隧道直连**：对端插件读描述文件、拉 `ssh -N -L` 隧道调用，不再需要远端 `dsh` 命令，也不再依赖 ACP 或 headless。
- 会话能力走 Host 公共的 `sessionController`，历史读本机 `$DSH_HOME/sessions/**`（zstd + JSONL v4，8 MB 上限）。
- 会话卡片「远程」面板与设置页的设备管理保持不变，底层从 ACP 换成桥接。

### 修复
- ACP 连接失败（子进程退出后再写 stdin）不再因未处理的 `error` 事件拖垮整个宿主进程。

### 安装
```sh
dsh plugin --profile web add @kaus-io/dsh-remote-instance@1.0.0-alpha05
```

### 兼容性
`engines.dsh`: `>=0.2.1-rc.3 <0.3.0`
