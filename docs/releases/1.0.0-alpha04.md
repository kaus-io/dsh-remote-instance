把远端 DSH 当成一台可操作的实例：看它自己的会话、读历史、直接对话。

### 新增
- **会话卡片「远程」面板**：设备 → 会话 → 对话；支持发送、停止当前回合、在指定目录新开会话，实时接收 `session/update`。
- **ACP 通道**（`ssh … dsh --profile acp`）：`session/list`、`session/new`、`session/resume`、`session/prompt`、`session/cancel`、`session/close`；每台设备一条连接，失败下次重连，卸载时关闭。
- **历史回放**：受限只读读取远端 `$DSH_HOME/sessions/**` 的 zstd 多帧日志（8 MB 上限），本地解压后解析 v4 JSONL 成消息（用户 / 助手 / 思考 / 工具调用）；读不到日志时退回「打开之后」的消息，并在界面标注来源。
- `instances` 返回本机身份（`hostname` / `platform`）与每台设备的 `note`，agent 能分辨本机与远程，以及哪台接着开发板。
- ACP 工具权限请求允许一次并在对话里留记录。

### 修复（发布前发现）
- ACP 请求的超时定时器不再 `unref`：Node 22 下事件循环可能先结束，请求会永远悬空。
- `session/prompt` 从无限等待改为 30 分钟上限。
- 连接关闭的兜底计时器会被清理，`dispose` 不再每个连接多等 3 秒。

### 安装
```sh
dsh plugin --profile web add @kaus-io/dsh-remote-instance@1.0.0-alpha05
```

### 兼容性
`engines.dsh`: `>=0.2.1-rc.3 <0.3.0`

### 已知限制
- ACP 协议没有 `session/load`，历史依赖远端日志；日志格式（zstd + v4 JSONL）变化时历史会退回实时消息。
- 远端必须已安装 `dsh`，且目标 profile 可运行。
